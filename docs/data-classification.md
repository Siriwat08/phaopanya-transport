# การจำแนกข้อมูล sensitive

เอกสารนี้สรุปการจำแนกตารางทั้ง 90 ตารางตามความไวของข้อมูล
เพื่อให้ทีมทราบว่าไฟล์ไหนสามารถ share ภายนอกได้ ไฟล์ไหนห้าม

## 🎯 ระดับการจำแนก

| ระดับ | ความหมาย | การจัดการ |
|---|---|---|
| **Public** | โครงสร้างตารางที่ไม่มีคอลัมน์ sensitive | สามารถเผยแพร่ได้ |
| **Config** | มีชื่อลูกค้า/ชื่องาน แต่ไม่มีค่าจริง | ใช้ใน Private repo เท่านั้น |
| **Business** | มี logic การคำนวณราคา/การอนุมัติ | Private repo เท่านั้น |
| **Sensitive** | มี PII, GPS, ข้อมูลพนักงาน | ห้าม commit ค่าจริงเด็ดขาด |

## 📊 สถิติการจำแนก (สรุป)

| หมวด | รวม | Public | Config | Business | Sensitive |
|---|---|---|---|---|---|
| User Tables | 29 | 5 | 1 | 8 | 15 |

## ⚠️ ตารางที่ sensitive ที่สุด

| ตาราง | เหตุผล |
|---|---|
| `ข้อมูลพนักงาน` | มี บัตรประชาชน, เบอร์โทร, อีเมล, ทะเบียนรถ |
| `SCGนครหลวงJWDภูมิภาค` | เก็บ GPS, รูปถ่าย, เวลา, การเคลื่อนไหว |
| `ข้อมูลการวางบิล` | มี ราคา, สถานะการอนุมัติ, Email พนักงาน/ผู้อนุมัติ |
| `ตารางงานประจำวัน` | มี Invoice No, Shipment No, ชื่อพนักงาน, ทะเบียนรถ |
| `แจ้งปัญหาระหว่างวัน` | มีรูป1/2/3, Lat/Long, ชื่อพนักงาน |

## 🚫 สิ่งที่ห้าม commit โดยเด็ดขาด

- ไฟล์ `.xlsx` ที่มีข้อมูลพนักงานจริง
- ไฟล์ `.gsheet` ที่ download จาก Google Sheets
- ไฟล์รูปภาพจริง (`.jpg`, `.png`) ที่ถ่ายจากแอป
- ไฟล์ CSV ที่มีข้อมูล transactional จริง (ไม่ใช่ documentation)
- App ID / Workspace UUID ใหม่ที่ยังไม่ review

## ✅ สิ่งที่ commit ได้

- `data/AppSheet_Documentation.csv` (เป็นเพียง schema/structure)
- ไฟล์ markdown ใน `exports/` (เป็นเพียง metadata)
- สคริปต์ `.gs` ใน `scripts/`
- เอกสารใน `docs/`
